Desktop workspace — which composition?

Same features in all three (Shape / Style / Export, toolbar, status). What differs is how the workspace treats the pot: as an object on a stage, a document in a workbench, or a piece in a gallery. Wireframes use the intended "craft studio" palette — warm dark, cream text, muted gold.

A — The Stage (recommended)

Full-bleed viewport; the pot is the hero. One floating glass panel carries Shape/Style/Export tabs; the toolbar is a slim grouped pill, not an icon strip. Modern object-editor feel (Spline, Womp) — matches the craft-studio identity best.

B — The Workbench

Anchored, resizable left panel flush to the edge (Figma / Shapr3D grammar), viewport owns the rest, slim top bar for view controls. Most conventional and most practical for long tuning sessions — but reads "tool" more than "studio".

C — The Gallery Deck
