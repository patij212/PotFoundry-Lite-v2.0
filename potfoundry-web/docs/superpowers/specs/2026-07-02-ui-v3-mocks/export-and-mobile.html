The rules encoded above

  • Fidelity, not "quality" — tiers named by what they're for (fast checks / print-ready / exhibition) with honest numbers: triangles, file size, detail in mm. Draft/Standard/High/Ultra jargon collapses to three choices (Standard merges into High).
  • The firing ceremony — export progress uses the pipeline's real stages (mesh → verify watertight → write); the pot glyph warms raw-clay → terracotta. Errors name the stage that failed and what to do.
  • Dignified gating — the free quota is a quiet gold arc, always visible, never a surprise. Hitting the limit swaps the CTA for "Continue with Pro" + one-line why. No slap-modals mid-flow.
  • Mobile: sheet with three stops (peek / half / full) — grabber handle, drag via transform (no React re-render per frame — fixes critique C3/C4), no overshoot spring. Peek keeps style name + tri count + Export button reachable. Toolbar collapses to two pills; gizmo hidden; 44px targets; safe-area insets.
  • The Blueprint compresses, never disappears — on mobile it becomes a slim strip above the sliders.
