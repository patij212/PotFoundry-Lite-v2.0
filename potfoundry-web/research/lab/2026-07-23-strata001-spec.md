## 0. Mandate and non-negotiable invariants

Goal: the validated-interval screen must **terminate and certify ≤ tol (0.01 mm true-3D) on piecewise-smooth analytic fields** — Voronoi/cellular first — at a triangle budget and wall-clock comparable to the smooth/cusp styles, and the machinery must generalize to a **shape-agnostic pipeline** where supporting a new style adds zero trusted code.

Performance and precision are co-equal requirements. Every phase gate in the plan cites these invariants by ID.

### Precision invariants (P-INV)

- **P-INV-1 — MAX-scoped, exact-analytic ruler.** All fidelity claims are MAX ≤ 0.010 mm true-3D perpendicular against the exact analytic target (targetSolid oracle / Φ projector), never p99-scoped, never grid-bound (DS-rim + analytic-scoring lessons).
- **P-INV-2 — Screen soundness is absolute.** `screenUpper ≥ trueUpper` on every audited cell. Dense oracle sampling is a **falsifier only** — it can refute a bound, never stand in for one.
- **P-INV-3 — Validated arithmetic everywhere in the trusted path.** Outward rounding (`outwardFloat64Interval`), closed one-sided semantics (a cell provably on one *closed* side resolves; equality belongs to the resolved side), refusal (never a bound) on unproven domains.
- **P-INV-4 — The field is never regularized.** No smoothmin, no accept-band, no tolerance reinterpretation. Creases are real features; we regularize the *partition*, never the target.
- **P-INV-5 — Method text + SHA versioned atomically.** Any change to screen rules updates the prepared proof text and its SHA pin in the same commit (`canonicalizeCertificationJson` / `computeValidatedResidualProgramSha256`; stale-pin lesson from the Codex audit).
- **P-INV-6 — Source contract.** Certification is of the compiled tape; tape ≡ CPU ≡ WGSL is carried by source-contract tests (4-copy Voronoi hash desync lesson). A certificate without a green contract is a certificate of the wrong surface.

### Performance invariants (F-INV)

- **F-INV-1 — OFF is free.** Every new screen feature is flag-gated; flag OFF ⇒ **byte-identical certification JSON SHA** (precedent: `setScreenSecondOrder` OFF = SHA 8e79440a).
- **F-INV-2 — ON is free on smooth tapes.** With the node rule ON, smooth-style certification: cell count Δ ≤ +1 %, wall-clock Δ ≤ +10 %. Defect channels are lazily allocated and zero-cost while no kink node fires.
- **F-INV-3 — Budget parity targets.** After S1 (node rule alone): Voronoi screen terminates ≤ 10⁷ cells. After S2 (conforming): full certify ≤ 10⁶ cells and ≤ 300 s wall (Gothic 287.5 s / WI 187 s class) on the dev machine.
- **F-INV-4 — Extraction is cheap.** Bisector-graph + chord assembly ≤ 2 s at defaults, O(sites) with the window lemma.
- **F-INV-5 — No hot-loop allocation.** Kernel arrays preallocated per compiled program; caps on every recursion/accumulation (Set-cap lesson).

## 1. Problem statement and measured baseline

The screen ([validatedResidualProgram.ts](../../src/geometry/targetSolid/validatedResidualProgram.ts)) certifies each candidate flat triangle by a triangle-exact centered mean-value enclosure of the residual, with forward-mode interval Jacobian channels; kinked `min`/`max`/`abs` nodes use the **Clarke subgradient hull** justified by Lebourg's mean-value theorem (method text at `validatedResidualProgram.ts:76`). Jump nodes are jump-guarded; unresolved cells downgrade to a first-order value-hull.

## 2. Root cause [DERIVED]

Lebourg's theorem is tight for the *worst Lipschitz function with the given generalized gradient* — one that may oscillate between branches arbitrarily. Our fields switch branches **exactly once across a clean analytic curve**. Consequences:

1. On a straddling cell, `co{∇d_i, ∇d_j}` has width `|û_i − û_j| = 2 sin(θ/2)` — **independent of cell size h**. The residual bound is stuck at first order: subdivision must reach `h* ≈ tol/(σ·slack)` (σ = true wall-gradient jump, slack = measured enclosure factor). With σ ~ O(0.1–1) mm/mm and slack ~ 10²–10³, h* ~ 10⁻⁴–10⁻⁵ mm along a graph of ~10³ mm ⇒ **N ~ 10⁷–10⁸ cells**. That is the hang, by arithmetic.
2. The hull also poisons composition: nine candidate site gradients hulled at the min node propagate as a fat interval matrix through the outer smooth chain; interval dependency multiplies widths — the gap between 10–15× at the node and hundreds-fold at the residual.
3. No better hull, no higher order, no budget fixes this. The missing information is *which branch is active where* — the switching structure. The method injects exactly that.

## 4. Method part A — conform the partition (budget lever, untrusted)

1. **Order-2 edges.** Same Sutherland–Hodgman clipper, run per ordered pair: inside the order-1 cell of site *i*, clip by bisectors of all pairs (j,k), j,k ≠ i. Survivors are the loci where the *second*-nearest switches. Graph roughly triples; complexity stays O(sites·window²).
2. **Chord-chain assembly** (the guides module's declared next increment): snap endpoints/junctions to the rational grid stations `conformingChordsByPatch` accepts ([annularSolidReferenceTessellation.ts:117](../../src/geometry/targetSolid/annularSolidReferenceTessellation.ts)); δ-merge near-degenerate junction vertices (hash accidents: near-coincident centers, near-cocircular quadruples); emit per-patch chains. Junction vertices shared by index between all incident chains and both flanks (u-seam-by-index lesson) — else the crease T-junctions.
3. **Periodicity + seam.** Build the graph in the animated, wrapped cellular frame with the *same* integer period as the field (`max(1, round(scale))` — must match `periodicCellularInt`; HexHive lesson: geometry AND hash periodic together). Chains crossing u = 0/1 split at the seam and go through the planarize path (cdt2d seam-spanner crash class).
4. **Chord sizing along the crease.** Straight in UV ≠ straight in 3D: the chain needs the 1-D validated chord bound along Φ∘line — `h_chord ≈ √(8·R·tol)` ≈ 2–3 mm at pot curvature ⇒ ~10³ chords, ~10⁴ extra cells. This is the entire asymptotic cost of a crease and equals what a knife-edge cusp already pays.

**Authority split (the design's keystone):** the graph and the insertion are **heuristic f64 and untrusted**. A missed locus ⇒ defect-charged straddling cells (terminates, budget-inflated). A false locus ⇒ harmless extra chords. No extraction bug can produce an unsound bound or a hang. Conforming is purely a budget lever; the certificate never cites it.

## 5. Method part B — the pivot + one-sided-defect node rule (trusted, generic)

**Why conforming alone is insufficient [DERIVED]:** a cell whose edge lies *on* the bisector still has overlapping `d_i`, `d_j` wide enclosures (equality on the shared edge), so the current overlap test fires the Clarke hull on every cell **touching** the graph — a one-cell-wide band that still needs h ≲ tol/σ ⇒ ~10⁵–10⁶ extra cells. The min node needs a rule that harvests one-sidedness.

**Rewrite identities (exact, pointwise):**

```
min(A,B) = B − relu(B−A)        max(A,B) = A + relu(B−A)        |A| = A + relu(−2A)
```

with the f1/f2 running-min cascade decomposing the same way (and reproducing `f2−f1 = |d_j−d_i|` exactly in the two-site regime).

**Node rule** (at a min node whose wide enclosures overlap; pivot B = centroid argmin, ties arbitrary — any pivot is sound):

- Emit the **pivot branch's** value/derivative channels only (thin centroid value is exactly `min` at the centroid; Jacobian channels stay single-branch and thin).
- Compute the **defect** `s = max(0, hi(ĝ))` where `ĝ` is the triangle-exact centered enclosure of the *smooth* difference `g = B − A` over the cell: `g(c)` from the thin run + the `∇g` channels hulled over the three exact vertex offsets — the same machinery the mean-value linear term already uses.
- Seed a **defect channel** with the one-sided interval: min → `[−s, 0]`; max → `[0, s]`; abs (pivot +A) → `[0, s′]`, `s′ = 2·max(0, −lo(Â))`.
- **Propagation:** defect channels flow forward multiplied by the *same* partial-derivative range factors the Jacobian chain rule already computes per op; at the end the defect adds to the residual enclosure. Lazily allocated; zero-cost while all-zero (F-INV-2). This is affine-arithmetic noise-symbol propagation with one interval-valued symbol.
- Clarke hull is **demoted to last-resort fallback** (defect refused/nonfinite); `ClarkeFired` telemetry becomes a regression canary that should read ~never.

**Soundness lemma [DERIVED — 5 lines, to be reviewed at S1]:** for x in the cell, `min(A,B)(x) = B(x) − relu(g(x))`; (i) `B(x) ∈ B̂(x)` by the existing pivot-branch mean-value soundness; (ii) `0 ≤ relu(g(x)) ≤ s` because `g` is smooth and `ĝ` is a sound centered enclosure; (iii) downstream, each op's defect factor is a sound enclosure of its partial derivative over the already-computed value ranges (identical factors to the first-order chain rule); non-covered downstream ops widen by their own rule or downgrade the run. A mischosen pivot only inflates `s` — soundness never depends on the choice.

**Tightness [DERIVED, gates at S1]:**

- Cell with the kink on/outside its boundary (conforming or interior): true `sup g ≤ 0`; the centered form overshoots the true sup by ≤ width(∇g-enclosure)·h = **O(h²)** ⇒ `s = O(h²)` — smooth-order convergence is preserved; touching cells behave like interior cells.
- Straddling cell: `s ≈ true straddle depth × true gradient jump` — the honest first-order error a flat triangle genuinely has across a crease, constant ≈ 1 instead of hull × dependency ≈ hundreds.

**Interplay:** the second-order pass keeps its current semantics (defect-fired ⇒ second-order-invalid ⇒ first-order fallback) — conservative, and second-order is parked anyway.

## 7. Generalization — the shape-agnostic pipeline

**Principle:** all shape knowledge lives in the compiled SSA tape; strata, loci, conforming, emitters, and screen rules derive from it mechanically. The three-layer invariant makes heuristic generic extraction safe: **soundness from the screen, termination from the node rule, budget parity from conforming.**

**Stage 0 — Compile (exists).** Style → tape via the shared SSA builder. The per-style cost floor of the whole pipeline is the target program + its source contract (P-INV-6). Endgame worth naming: single-source codegen (tape → WGSL/CPU/f64 twin) retires the copy-desync class and makes "certify what you ship" true by construction.

**Stage 1 — Stratification pass (mechanical tape walk).** Every non-smooth op emits a *switch functional* (a smooth sub-tape whose level set is its kink locus) + a class tag:

| Tape op | Switch functional | Class | Mechanism |
|---|---|---|---|
| `min`/`max` | `left − right = 0` | C1 crease | conform + pivot/defect |
| `abs` | `arg = 0` | C1 crease | same |
| clamp/smoothstep pieces | `arg − edge = 0` | C1 or provably benign (outer derivative vanishes at the station — static tape fact for smoothstep endpoints) | conform or nothing |
| `floor`/`fract`/`round` | `arg − k = 0`, k ∈ ℤ ∩ interval-range(arg) | C0 jump family | curtain / double-valued wall, or **certified de minimis** (interval-bound the jump; provably < tol with margin ⇒ drop from conforming; screen still guards) |
| `step`/`sign` | `arg − edge = 0` | C0 jump | same |
| `pow(base, e<1)`, `sqrt` at 0 | `base = 0` | cusp | pinned vertex + value-hull cells (cone-fan on the mesh side) |
| `div`, `atan2` origin | denominator / origin | pole | refusal domain (existing discipline) |
| hash/pcg2d | inherits floor's cell boundaries | C0 only if the hash value leaks directly into geometry | lint (HexHive noise-seam class) |

Refinements: **activity pruning** (interval feasibility of joint minimality ⇒ O(n) true edges, not O(n²) candidates) and **hierarchical stratification** (topological order; an outer switch functional is traced on branch-pinned tapes within regions already discovered for its predecessors).

**Stage 2 — Locus geometry, three tiers, zero added trust:**

- **Tier 1 — recognizers (exact):** jittered-lattice Euclidean min → order-k Voronoi lines (subsumes the guides; closes the GeoStar conforming-graph gap as an instance); affine/separable arguments → exact lines/stations (layered floors, HexHive lattice, spokes); 1-D periodic profiles → interval-Newton stations.
- **Tier 2 — generic implicit tracer (heuristic):** quadtree sign-localization by interval evaluation of the g sub-tape (reuses the screen's interval engine), predictor–corrector with interval-Newton correction, saddle handling by subdivide-until-separated **with a hard cap** (crossing-contour trap), fall through to Tier 3 on failure. Gyroid ridge-network class lives here.
- **Tier 3 — lazy in-screen cutting (guaranteed floor):** on defect-dominant cells, cut by the zero line of the centered linear model of the firing node's difference — children are one-sided up to O(h²). Needs no extractor; near-parity for any compiled style.

**Stage 3 — Conform + emit.** Class-tagged chains dispatch to the four proven terminal mechanisms: smooth region → grid emitter; C1 crease → constraint edges (`conformingChordsByPatch` / `constraintEdges` + msurf sizing); C0 jump → curtain/double-valued wall; cusp → cone-fan. This *is* the PROD-TIERC region mesher: regions = tape strata.

**Stage 4 — Screen with per-op rules only** (pivot/defect, jump guards, value-hull, refusal; Clarke as fallback with telemetry). Termination theorem becomes style-independent.

**Stage 5 — Certificate:** per-op rules certified once, globally; adding a style adds zero trusted code.

**Honest limits:** parity scales with **stratum measure** (crease length, jump count) — agnostic to shape *class*, not shape *complexity*; the pipeline should report stratum measure as a budget forecast. Tracer fragility at tangencies/degenerate junctions is capped-then-degraded, never load-bearing. Benignity proofs are optimizations — the screen still guards them (direction of dependency inviolate).
