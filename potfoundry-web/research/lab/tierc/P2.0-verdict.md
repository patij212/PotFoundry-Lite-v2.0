## Why the earlier "density-invariant" conclusion was wrong

GLOBAL featureLevel escalation (A3, Addendum 14) failed via the relief-chord-cliff: touching EVERY
cell — including fine ones that didn't need it — spawned new straddle facets, +134% survivors. LOCAL
escalation touches ONLY the genuinely-flagged hot facets and never perturbs already-good cells, so it
does not share that failure mode. The "density-invariant" verdict was an artifact of testing global,
not local, refinement.

**Mechanism (the real one):** the knee is C1-not-C2 (continuous value, discontinuous SLOPE). Local
h-refinement CONVERGES on this class — each smaller facet chords a shrinking neighborhood of a
value-continuous kink (bounded sagitta, shrinks with size). A true value discontinuity (C⁻¹ seam)
could not be bridged; a slope kink can. Reduction rate afterU1 ~0.59 (milder than a smooth-C2
chord∝extent²'s 0.25, consistent with slope-discontinuity proximity) but still ≤0.01 within 2 levels.

## Methodology correction (load-bearing)

The task's literal "anchor on the on-knee vertex, bisect its longer edge" heuristic gave ZERO
improvement (facet 1336852 unchanged at 2 levels) — because EVERY mesh vertex already sits ~1e-6mm on
the analytic surface (`outerXyz` evaluates `rA` at every vertex), so "distance-to-isolevel" is not a
geometric anchor. The agent diagnosed this from raw per-vertex Newton distances and switched to
UNIFORM QUADRISECTION (bisect all 3 edges at analytic-lifted midpoints — the assumption-free standard
local-refinement primitive AND the faithful proxy for a real quadtree featureLevel+1/+2). That is the
valid, decisive method.
